Open **Settings** — macOS: ⌘, ; iPad: the gear icon in the toolbar — for four sections.

## Author

- **Full Name** — appears on the cover page byline as "Written by …"
- **Contact Info** — appears on the cover page bottom-left

These are the defaults for every issue. Individual issues and graphic novels can override them in the Inspector's **Info** tab.

:::note[The document's own author wins]
Export and preview use the author and contact stored **in the document** when it has them, and fall back to these settings when it doesn't. So exporting a collaborator's script stamps their name on the cover page, not yours.
:::

## Appearance

**Color Scheme** — System, Light, or Dark.

## Library Location

**iCloud Drive** or **On My Device**, plus the move itself. See [Where your Library lives](/guides/library/#where-your-library-lives) for what each option means and how the migration works.

## About

The version you're running and the build it was made from. Worth quoting if you [get in touch about a problem](/contact).

---

Editor font size isn't a setting — change it live from the **View** menu with ⌘+ / ⌘- / ⌘0 (Bigger / Smaller / Normal).
