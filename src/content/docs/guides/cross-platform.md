---
title: Cross-Platform Notes
description: What works on macOS and iPad, and where the two platforms differ.
---

ComicDraft runs on **macOS** and **iPad**. (There's no iPhone build — a comic script page doesn't fit on a phone.) The feature surface is the same on both — same shortcuts, same library, same documents, same export formats bar one.

| Capability | macOS | iPad |
|------------|-------|------|
| All ⌘1-9 element shortcuts | ✓ | ✓ (with hardware keyboard) |
| Format Bar | ✓ | ✓ |
| Inline formatting shortcuts | ✓ | ✓ (with hardware keyboard) |
| PDF export | ✓ | ✓ |
| DOCX export | ✓ | — |
| TXT export | ✓ | ✓ |
| Open a document from outside the Library (⌘O) | ✓ | ✓ |
| Open by double-clicking the file | ✓ (Finder) | ✓ (Files app) |
| Reveal the document's file | ✓ (Show in Finder) | Share sheet instead |
| Choose where a duplicate is saved | Save panel | Document picker |
| Library location + migration | ✓ | ✓ |
| Spell check | ✓ (system-wide learned dictionary) | ✓ (per-app learned list) |
| Menu bar | ✓ | ✓ (hold ⌘ to see shortcuts, or attach a hardware keyboard) |

Files created on one platform open transparently on the other.

## Editing the same issue on two devices

If an issue is open on your Mac and your iPad at once, ComicDraft won't let one device's save overwrite a version the other has already changed. Rather than letting whichever device autosaved last quietly win, it refuses the write and tells you: their version stays on disk, yours stays in the editor. Closing and reopening the issue takes the other device's version.
